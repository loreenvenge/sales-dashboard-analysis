# Sales Dashboard Analysis

Interactive sales analysis for a retail company to track revenue, products and regions.

### Business Questions Answered:
- What is total revenue and average basket size?
- Which product sells most?
- Which region / branch is underperforming?
- What is the monthly revenue trend?

### Key Insights:
- Harare contributes ~40% of total revenue
- Cooking Oil and Rice are top revenue products
- Identified a drop in sales in one region - recommended promotion

### Tools Used:
Python, Pandas, Matplotlib, Power BI / Excel

### How to Run:
python sales_analysis.py

### Files:
- sales_data.csv - Clean data for Power BI
- monthly_revenue.png, revenue_by_product.png, revenue_by_region.png - Dashboard charts
